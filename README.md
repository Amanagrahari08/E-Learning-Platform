# 🎓 E-Learning Platform (GUI Based)

A GUI-based E-Learning Platform developed using Java Swing, JDBC, and MySQL.  
This desktop application provides a structured environment for managing students, teachers, and academic activities efficiently.

---

## 🚀 Features

- 🔐 Secure Login & Registration System
- 👨‍🎓 Student Portal Dashboard
- 👨‍🏫 Teacher Portal Dashboard
- 🗄 MySQL Database Integration
- 📊 Role-Based Access Control
- 🖥 Interactive Java Swing GUI

---

## 🛠 Technologies Used

- Java (Core Java)
- Java Swing (GUI)
- JDBC
- MySQL
- OOP Concepts
- IntelliJ IDEA

---

## 🗃 Database Structure

Main Tables:
- users
- students
- teachers
- courses (if implemented)
- records

---

## ▶ How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Configure MySQL Database
4. Update database credentials in the `DatabaseConnection` class
5. Run the `SplashScreen` or `Login` class

---

## 📌 Key Highlights

- Separate dashboards for Students and Teachers
- Real-time database connectivity using JDBC
- Clean modular structure
- Practical implementation of OOP principles
- GUI-based navigation with icons support
